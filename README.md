# AI Tools Setup Portfolio Project

## Objective
This project documents the installation and setup of AI-assisted development tools as part of the application process.

## Tools Installed
- Cursor IDE
- Claude Code Extension
- Codex Extension
- Git
- GitHub

## Steps Completed
1. Installed Cursor IDE.
2. Created a GitHub account.
3. Created a public GitHub repository.
4. Opened the repository in Cursor.
5. Installed Claude Code extension.
6. Installed Codex extension.
7. Logged into both extensions.
8. Created this README file.
9. Committed changes to Git.
10. Pushed repository to GitHub.

## Challenges Encountered

### Git Not Installed
Issue: When trying to clone the repository in Cursor's terminal, I got an error: "the term 'git' is not recognized as the name of a cmdlet, function, etc."
Solution: I discovered Git was not installed on my system. I downloaded and installed it from git-scm.com, restarted Cursor, and the `git` command worked afterward.

### Empty Repository Warning
Issue: After cloning, I received a warning that the repository appeared empty.
Solution: This was expected, since I hadn't added any files yet. I created the README.md locally to begin documenting the project.
